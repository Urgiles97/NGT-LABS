# NGT-LABS | Networking & Cybersecurity Labs

## 📌 Overview

Welcome to **NGT-LABS**, a hands-on collection of networking and cybersecurity labs designed to build practical skills in network configuration, troubleshooting, infrastructure, and security.

This repository documents my progression through foundational and intermediate networking and cybersecurity concepts using hands-on labs, network simulations, configurations, and troubleshooting exercises.

The labs focus on understanding how networks are designed, configured, segmented, routed, and secured in real-world environments.

---

## 🎯 Objectives

The primary goal of NGT-LABS is to develop practical experience with:

- Network configuration and troubleshooting
- IP addressing and subnetting
- VLAN configuration and network segmentation
- LAN and WAN concepts
- IP routing
- Core networking protocols
- Network models and architecture
- Cisco switching and routing
- Cybersecurity fundamentals
- Network security concepts
- Connectivity testing and troubleshooting
- Command-line configuration
- Network documentation

---

# 🧪 Lab Categories

## 🌐 1. IP Addressing & Subnetting

Labs focused on understanding IPv4 addressing, subnet masks, network ranges, and subnetting.

### Topics

- IPv4 addressing
- Private and public IP addresses
- Subnet masks
- CIDR notation
- Network addresses
- Broadcast addresses
- Usable host ranges
- Subnet calculations
- Subnetting practice
- Troubleshooting IP addressing

---

## 🔀 2. VLANs & Network Segmentation

### Topics

- VLAN creation
- VLAN assignment
- Access ports
- VLAN segmentation
- Broadcast domains
- VLAN verification
- Switch configuration
- Connectivity testing
- Inter-VLAN communication
